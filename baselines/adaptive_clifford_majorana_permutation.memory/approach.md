# Approach

The submission starts from the repository's geometric ternary multitree
construction, inlined in `encode.py`, and improves it using two exact
canonical transformations:

1. Symplectic Clifford transvections generated by arbitrary Pauli axes.
2. Unrestricted permutations of the individual Majorana generators.

Each move preserves all Majorana anticommutation relations. The hopping and
onsite terms are recomputed from the transformed Majoranas, and the repository's
frozen verifier remains the final validity check.

The objective minimizes maximum Hamiltonian Pauli weight first, then the number
of terms at that maximum, then the remaining weight histogram. A size-independent
work rule scales the number of proposals inversely with the number of Hamiltonian
terms. No record table, lattice-size lookup table, or branch on `M`, `Lx`, or `Ly`
is used. If the target reduction is not reached, the implementation returns the
unmodified valid seed, so it cannot make the maximum weight worse.

Exploratory runs found one-weight reductions over the seed at 5x5, 6x6, 8x8,
9x9, 10x10, 11x11, 13x13, and 14x14. The exact outcome produced by the packaged
budget should be read from the independent verifier rather than inferred from
those exploratory runs.

The final folder was structurally validated with `validate_manifest` and
`validate_encode_source`. Its exact `encode.py` passed `check_at_size` at 3-9,
11-12, and 14-15 on 2026-09-05; the local sweep was stopped before 10 and 13 to
avoid duplicating the repository admin's authoritative full-range inbox run.
